本地AI（在线部署版）V7  使用说明
================================================================

一、软件简介
----------------------------------------------------------------
本地AI 是一款桌面端本地大模型对话软件。软件本身是一个轻量的客户端界面，
负责对话交互、文件解析、本地服务调度，并调用本机 Ollama 推理服务完成模型运算。
所有对话均在本机完成，不上传云端，断网后仍可使用（首次部署需联网下载）。

本安装包为「软件本体」版本：不含推理引擎，也不含任何模型文件。
首次启动时，软件会打开部署向导，由您选择要使用的模型，再由软件自动联网
下载运行环境与模型文件。

二、安装与首次启动
----------------------------------------------------------------
1. 双击安装包，按提示完成安装（默认目录为 C:\本地AI在线部署版）。
2. 安装完成后启动「本地AI」（桌面或开始菜单均可）。
3. 首次启动进入「部署向导」页面，共三步：
   第 1 步 运行环境：软件自动从国内加速镜像下载 Ollama 推理引擎并解压，
          下载源为 gh-proxy 镜像，失败会自动回退官方地址。
   第 2 步 选择模型：可选 通义千问 1.5B / 3B / 7B，默认 7B。
          模型权重来自魔搭社区（ModelScope）官方仓库直链下载。
   第 3 步 部署进度：页面显示百分比、已下载大小、实时速度、预计剩余时间；
          失败可重试，也可随时点「取消」。
4. 部署完成后点击「进入聊天界面」，之后每次启动都会直接进入聊天界面。

三、各模型的体积与配置建议
----------------------------------------------------------------
    1.5B   约 1.0 GB    4 GB 内存即可，老电脑/轻薄本首选
    3B     约 2.0 GB    8 GB 内存较流畅
    7B     约 4.4 GB    建议 16 GB 内存，效果最好（默认）

磁盘请预留：模型体积 + 约 1 GB 临时空间（部署完成后临时文件会自动清理）。

四、安装目录说明
----------------------------------------------------------------
    C:\本地AI在线部署版\
      ├─ 本地AI.exe              主程序（软件本体）
      ├─ web\                    界面文件（部署页 setup.html、聊天页 chat.html）
      ├─ Ollama\                 运行环境（首次部署时自动下载解压）
      │    └─ ollama.exe
      ├─ models\                 模型目录（模型权重与清单存放于此）
      ├─ run_mode.json           运行模式配置（gpu / cpu / hybrid）
      ├─ _setup_tmp\             部署临时目录（完成后自动清理）
      ├─ 使用说明.txt
      └─ 软件版权声明.txt

五、运行模式
----------------------------------------------------------------
聊天界面右上角可切换运行模式，切换后本地推理服务会自动重启：
    gpu     优先使用显卡推理（有 NVIDIA 显卡时推荐）
    cpu     仅用处理器推理（无独显或显存不足时使用）
    hybrid  显卡 + 处理器联合推理，由引擎按显存自动分配
选择结果保存在 run_mode.json，下次启动沿用。

六、添加更多模型（可选）
----------------------------------------------------------------
本软件默认只部署您选择的那一个模型。如需添加其他模型，可在命令行中操作：
    1. 打开命令提示符，进入安装目录：
         cd /d "C:\本地AI在线部署版"
    2. 指定模型目录并下载新模型（以 qwen2.5:14b 为例）：
         set OLLAMA_MODELS=C:\本地AI在线部署版\models
         Ollama\ollama.exe pull qwen2.5:14b
    3. 也可导入本地 GGUF 权重文件：
         Ollama\ollama.exe create mymodel -f Modelfile
       （Modelfile 内容示例：FROM ./your-model.gguf）
    4. 完成后重启「本地AI」，聊天界面模型下拉框即可看到新增模型。
注意：新模型版权归各自权利人所有，请自行确认其许可与合规性。

七、常见问题
----------------------------------------------------------------
Q1：部署页一直显示「正在下载运行环境（Ollama）」？
    首次下载约 60 MB，网络较慢时请耐心等待；若长时间无进度，点「取消」后
    重新点「开始部署」即可换源重试。

Q2：提示「模型注册失败」？
    多为磁盘空间不足或推理服务未启动所致。请确认 models 目录所在分区有足够
    空间（7B 需约 5 GB），再点「开始部署」重试。

Q3：部署完成后聊天没有回复？
    查看界面顶部状态是否为「AI服务：开 / 已连接」；若为关闭，点右侧开关
    启动服务，或切换运行模式后重试。

Q4：想换一个模型，需要重装软件吗？
    不需要。重新运行部署向导选择另一模型即可（旧模型会保留在 models 目录）。

Q5：软件会联网上传我的对话吗？
    不会。除首次部署下载环境与模型外，软件不访问外部网络，对话全部在本机完成。
