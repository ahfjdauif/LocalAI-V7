# 本地AI（在线部署版）V7

一款基于 [Ollama](https://github.com/ollama/ollama) 二次封装的 **Windows 桌面本地大模型客户端**。

软件本体只有一个主程序和一套前端界面：所有对话推理都在本机完成，不经过任何云端接口，断网后依然可用（仅首次部署环境与模型时需要联网）。

> **本仓库只包含软件本体源码**，不包含 Ollama 运行环境和任何模型权重文件。这些内容由程序首次启动时的「部署向导」自动联网下载。

---

## 特性

- **全程本地推理**：对话数据不出本机，无云端中转。
- **三步部署向导**：运行环境 → 选择模型 → 下载进度，失败可重试、可随时取消。
- **多源测速择优**：环境下载支持镜像与官方源自动探测速度并择优，模型权重走 ModelScope 官方直链。
- **多线程分段下载 + SHA-256 校验**：大体积模型下载支持断点续传、分片并行、完整性校验。
- **三种运行模式**：`gpu` 显卡优先 / `cpu` 纯处理器 / `hybrid` 显卡与处理器联合，切换后推理服务自动重启，选择结果持久化。
- **内置本地 HTTP 服务**：前端与后端通过本机回环端口通信，不对外暴露。
- **原生启动画面**：启动时先显示原生窗口，界面首帧渲染完成后自动关闭，避免白屏。
- **模型管理页**：查看已装模型、体积、参数，并支持继续拉取其他模型。

## 支持的模型

| 模型 | 体积 | 建议内存 | 适用 |
| --- | --- | --- | --- |
| Qwen2.5 1.5B | 约 1.0 GB | 4 GB | 老电脑 / 轻薄本 |
| Qwen2.5 3B | 约 2.0 GB | 8 GB | 主流配置 |
| Qwen2.5 7B | 约 4.4 GB | 16 GB | 效果最好（默认） |

磁盘需预留：模型体积 + 约 1 GB 临时空间（部署完成后临时文件自动清理）。

## 从源码运行

需要 Windows + Python 3.10 及以上。

```powershell
pip install pywebview
python src\app.py
```

首次运行会进入部署向导，按提示下载 Ollama 运行环境与所选模型。程序默认使用 `127.0.0.1:21434` 作为界面服务端口、`127.0.0.1:11500` 作为 Ollama 端口（特意避开系统自带 Ollama 的 `11434`，两者可共存）。

## 打包安装包

使用 [Inno Setup 6](https://jrsoftware.org/isinfo.php) 打开 `installer\本地AI在线部署版.iss` 编译即可。打包前需先用 PyInstaller 将 `src\app.py` 打成单文件 `build\dist\本地AI.exe`（安装脚本中已按此路径引用）。

安装包仅包含软件本体，不含运行环境与模型，因此体积很小。

## 常见问题

**Q：部署页一直卡在「正在下载运行环境」？**
首次下载约 60 MB，网络较慢请等待；若长时间无进度，点「取消」后重新开始即可换源重试。

**Q：提示「模型注册失败」？**
多为磁盘空间不足或推理服务未启动。确认 `models` 所在分区空间充足（7B 需约 5 GB）后重试。

**Q：部署完成但聊天没有回复？**
查看界面顶部状态是否为「已连接」；若为关闭，点开关启动服务，或切换运行模式后重试。

**Q：想换模型要重装吗？**
不需要。重跑部署向导选择另一模型即可，旧模型会保留在 `models` 目录。
